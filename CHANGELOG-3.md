## 2026-09-26 (evening) — Hot Slips gets its own tab; the v3 ticket (Danny)

Danny confirmed the reading before any code, then answered three questions: two sections not one merged list (C), hot slips ignore the board filters, and the extra width is for readability.
- **Mockup first:** https://claude.ai/artifact/BemZVPCCov9ftUrCBLSpt4 , built from the live page's own CSS and that afternoon's real slips. v1 = the old picks list, two per row. Danny then sketched a ticket in Excel (a small table per game: date/time and pick type on top, home team, away team, each with its chance, the pick shaded green) -> v2 stacked those tables in a card; "you can't tell what game the third one is" (a total drawn as O/U rows) -> totals redrawn as team rows carrying O and U; then "games running left to right" -> v3, one strip per slip.
